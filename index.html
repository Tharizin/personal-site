Live Server can’t run this site

This is a Next.js app, so it needs a running server. Live Server only hands out files as-is — it can’t execute the .tsx source, so you get a blank or broken page.

Open a terminal in this folder and run:

npm run dev

Then open http://localhost:3100. To edit content, go to http://localhost:3100/admin.

Stop the server with Ctrl+C in that terminal. This page is a signpost only — it is not part of the website and never gets deployed.
